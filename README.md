## Widget Personalization Tool

Инструмент для массового удаления/добавления виджетов в JSON-конфигах и сравнения нескольких файлов с генерацией результирующих JSON.

### Возможности

- ✅ Массовое удаление виджетов по ID из нескольких JSON-файлов
- ✅ Добавление новых виджетов после указанного ID
- ✅ Автоматическое сравнение структуры файлов и выбор стратегии вывода
- ✅ Валидация входных данных с детальными сообщениями об ошибках
- ✅ Отчёт о сегментах, где не удалось выполнить операцию
- ✅ Модульная архитектура с полным покрытием тестами

### Подробное использование

#### Удаление виджетов

```
Выберите действие:
1 - Удалить виджеты по ID
2 - Добавить виджеты после указанного ID
Введите номер операции (1/2) и нажмите Enter: 1

Введите ID виджетов для удаления через запятую: widget1, widget2, oldWidget
```

#### Добавление виджетов

```
Выберите действие:
1 - Удалить виджеты по ID  
2 - Добавить виджеты после указанного ID
Введите номер операции (1/2) и нажмите Enter: 2

После какого ID вставлять? Введите ID: mainContent

Введите JSON массив виджетов для добавления:
[{"id":"newWidget","customizable":true,"title":"Новый виджет"},{"id":"anotherWidget","customizable":false,"title":"Ещё один"}]
```

#### Пример входного JSON

```json
{
  "widgets": [
    {
      "segment": "header",
      "widgets": [
        {"id": "logo", "customizable": true, "title": "Логотип"},
        {"id": "menu", "customizable": true, "title": "Меню"}
      ]
    },
    {
      "segment": "content", 
      "widgets": [
        {"id": "mainContent", "customizable": true, "title": "Основной контент"},
        {"id": "sidebar", "customizable": false, "title": "Боковая панель"}
      ]
    }
  ]
}
```

### Стратегии вывода

#### 1. Один файл
Если в `input_jsons/` только один файл:
- Создаётся `{filename}_new.json` в `output_jsons/`

#### 2. Идентичные файлы  
Если все файлы имеют одинаковую структуру виджетов:
- Создаётся единый `new_merged.json` в `output_jsons/`

#### 3. Различные файлы
Если файлы имеют разную структуру:
- Создаются отдельные `{filename}_new.json` для каждого файла

### Обработка ошибок

#### Некорректные входные файлы
```
Найдены некорректные JSON файлы. Процесс остановлен. Исправьте следующие файлы:
- corrupted.json
- empty.json
```
**Результат:** Процесс останавливается, выходные файлы не создаются.

#### Отсутствующий after_id при добавлении
```
config.json | header - не получилось добавить, т.к. отсутствует виджет "missingWidget"
config.json | footer - не получилось добавить, т.к. отсутствует виджет "missingWidget"
```
**Результат:** Виджеты добавляются в доступные сегменты, сообщения выводятся для недоступных.

#### Неверный JSON при добавлении
```
Неверный JSON. Добавление будет пропущено.
```
**Результат:** Операция добавления пропускается, но валидация after_id всё равно выполняется.

### Расширенная функциональность

#### Сравнение файлов
Система сравнивает полную сигнатуру виджетов:
- Название сегмента
- ID виджета  
- Флаг customizable
- Заголовок виджета

#### Безопасность операций
- Все операции выполняются на копиях данных
- Исходные файлы не изменяются
- Валидация на каждом этапе

#### Гибкость добавления
- Можно добавлять несколько виджетов одновременно
- Виджеты вставляются после каждого найденного экземпляра after_id
- Поддержка любых JSON-структур виджетов

### Тестирование

#### Запуск тестов
```bash
pytest -q
```

#### Покрытие тестами
- **utils/io_utils**: Валидация входных файлов, обработка пустых/битых JSON
- **widgets/operations**: Удаление/добавление виджетов, генерация сигнатур
- **utils/prompts**: Интерактивные диалоги, валидация пользовательского ввода  
- **processing/pipeline**: Полный сценарий обработки, стратегии вывода

#### Примеры тестов
```bash
# Запуск с подробным выводом
pytest -v

# Запуск конкретного теста
pytest tests/test_widgets_operations.py::test_remove_widgets -v

# Запуск с покрытием
pytest --cov=. --cov-report=html
```
